# 切り抜き雛形「N」（くすみピンク・カード型）

- 承認：本人（2026-11-20、壁際族 C修正版02 を見て「良いと思います！」「これを雛形にして貰えたら嬉しいです」）
- 見本：`切り抜き候補_ライブで壁際に並ぶ人、やめてください_C修正版02.mp4`（17LIVE録画／20261118-230925_1045033）
- 道具：`tools/make_n.py`（内容ファイル → 完成動画）、パラメータは `templates/layout_N.json`
- この文書は見た目の決まりをまとめたものです。切り抜き方針への正式な反映はZが担当します。

## 1. 画面の組み立て（1080×1920、24fps）

| 要素 | 位置・大きさ | 見た目 |
|---|---|---|
| 背景 | 全面 | くすみピンクの縦グラデーション（上 RGB 110,82,96 → 下 58,40,49）。カードの影（黒55%、右下に12/22pxずらし、ぼかし22） |
| カード（映像） | 左上 (135,330)、810×1170、角丸36px | 元映像（720×1280）の上から1040行を切り出して1.125倍。下側約19%はカット（アプリの操作欄で隠れる部分のため）。縁取り3px（淡い藤色 #E8C6D3、透明度25%） |
| タイトル | 上の余白（上端149px〜） | 2行。1行目＝小さめ黄色（44px、#FFE500）でフックや問いかけ。2行目＝大きめ白（66px）で本題。黒の縁取り3px |
| 字幕（本人の発言） | カードの中、下端1449px | 白・太字64px。1枚の角丸の座布団（濃い色、半透明）にまとめて表示。1行16文字まで、2行まで |

| 終わり | 最後の3秒、y=420 | 角丸の小さな吹き出しに「17LIVEで配信中」。「本編は…」の字幕は出さない（本編はもう見られないため） |

## 2. 安全範囲（YouTube Shorts／TikTok）
- 文字の上端は134px（上7%）より下。雛形の実測は149px。
- 文字の下端は1497px（下22%）より上。字幕の下端は1449px。
- 下半分の文字はアプリ右側のボタン列（x>930付近）にかからない。
- 書き出し前に `safezone.py` で全コマ（0.5秒ごと）を確認する。

## 3. 字幕とコメントの決まり
- 本人がコメントを**読み上げている間は字幕を出さず、吹き出しだけ**を表示する（二重表示を避けるため）。読み上げのあとの「…とか言って」などは字幕にする。
- 本人がコメントに反応して話している場面は、吹き出しと字幕を両方出してよい。
- **吹き出しにするのは、本人が読み上げたコメントか、話の中身に関わるコメントだけ**。「すごい」「まじかよ」「上手い」「乾杯」のような簡単な同調・反応のコメントは出さない（本人の指示、2026-11-20）。
- 第三者（家族・店員など）の声は字幕にしない。本人が誰かのセリフを再現して話している場合は、誰のセリフかが分かる書き方にする。
- 字幕の文言は、2種類以上の音声認識とコメントログの照合で確定させる。確定できない箇所は報告書に「未確認」と書く。

## 4. 音と同期
- 元素材は1回だけデコードする。映像はフレーム番号で、音声はサンプル数で切り出す（48kHz、1フレーム＝2000サンプル）。連結は concat フィルタで行う（`tools/build_clip.py`）。
- 背景は元映像から作った下地の上に重ねる（静止画を下地にすると映像が1フレーム遅れるため）。
- 録画自体に映像と音声のズレがある場合（11/19の復旧録画など）は、区間ごとに `voff`（映像を取る位置の秒数のずれ）を指定する。ズレ量は区間ごとに測る。
- 区間ごとに `speed`（整数倍の早送り。映像はk枚に1枚、音声はatempoで縮めて長さを合わせる）と `mute`（無音）を指定できる。
- 音量は −14 LUFS（2パスの loudnorm）。最後の0.3秒をフェードアウトする。

## 5. 内容ファイルの書き方（`clips/*.json`）
```json
{
 "title": "動画の正式名（作業用）",
 "title_top": "黄色の1行目（フック・問いかけ）",
 "title_main": "白の2行目（本題）",
 "source": {"recording_id": "…", "raw_clip": "…"},
 "card_crop_y": 0,
 "segments": [
  {"name": "区間名", "in": 12.0, "out": 18.5, "voff": 0,
   "captions": [{"s": 12.2, "e": 14.0, "text": "本人の発言\\N2行目"}],
   "comments": [{"s": 12.0, "e": 15.0, "text": "コメント原文（[[強調]]可）"}]}
 ]
}
```
- 時刻は元素材の秒で、区間の in/out は1/24秒の格子に合わせる。
- 実行：`python3 tools/make_n.py clips/xxx.json 元素材.mp4 出力.mp4`
