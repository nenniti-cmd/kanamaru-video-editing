# C Drive窓口（Claude Code ⇔ Google Drive）

クラウドで動く Claude Code（C）が、Driveコネクタのサイズ上限（取得10MB／送信は1回約3MB）を超えるファイルを、
Google Drive の「17LIVE録画」フォルダ以下に置くための窓口です。
本人の Google アカウントで動く Apps Script（無料）を使います。

## 運用方針
- この窓口は、**Cが成果物をDriveに置くときだけ**使う。
- 素材の受け取りは、他のAIとも共通の方式（Driveの共有リンク）のままとし、窓口は使わない（2026-11-19 本人決定）。

## できること・できないこと
- できる：17LIVE録画フォルダ以下での「新規作成」「一覧」「情報取得」「ダウンロード」
- できない：上書き、削除、移動、共有設定の変更、17LIVE録画フォルダ以外へのアクセス
- 同じフォルダに同名のファイルがあるときは作成を拒否する
- すべての操作に合言葉が必要。合言葉はマイドライブ直下の「C窓口キー_共有禁止.txt」にだけ保存する。
  CはDriveコネクタ経由でこのファイルを読み、合言葉をコードや設定に残さない。

## 初回設定（本人がPCのブラウザで1回だけ。10分程度）
1. `Code.gs` の中身をすべてコピーする（GitHubのファイル画面右上の「Copy raw file」ボタン）。
2. https://script.google.com/ を開き、「新しいプロジェクト」を押す。
3. 左上の「無題のプロジェクト」を押し、名前を「C Drive窓口」に変える。
4. エディタの中身（`function myFunction() {…}`）をすべて消して、コピーしたコードを貼り付け、保存する（Ctrl+S／⌘+S）。
5. 上部の関数の選択欄で `setup` を選び、「実行」を押す。
   - 「承認が必要です」→「権限を確認」→ 自分のアカウントを選ぶ
   - 「このアプリは Google で確認されていません」と表示されたら、「詳細」→「C Drive窓口（安全ではないページ）に移動」→「許可」
     （自分で作ったスクリプトなので、Googleの審査を受けていないという意味の表示です）
   - 下の実行ログに「設定完了」と出れば成功。マイドライブ直下に「C窓口キー_共有禁止.txt」ができる（**共有しないこと**）。
6. 右上の「デプロイ」→「新しいデプロイ」→「種類の選択」の歯車 →「ウェブアプリ」
   - 説明：C窓口
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（Cはログインできないため。合言葉がなければ何もできない）
   - 「デプロイ」を押す（もう一度承認を求められたら、5と同じように許可する）
7. 表示された「ウェブアプリ」のURL（`https://script.google.com/macros/s/…/exec`）をコピーして、Cのチャットに貼る。

## 運用
- C側：`python3 tools/drive_relay/drive_relay.py upload <ファイル> <フォルダID>`
  - アップロード後に、Drive上のサイズとMD5が一致するかを自動で確認する
- 止めたいとき：Apps Scriptで「デプロイ」→「デプロイを管理」→「アーカイブ」（URLが無効になる）
- 合言葉を変えたいとき：`setup` をもう一度実行する（古い合言葉はすぐ無効になる）
- スクリプトを更新したとき：「デプロイを管理」→ 鉛筆アイコン →「バージョン：新バージョン」→「デプロイ」（URLは変わらない）
- 実行の記録：Apps Scriptの左メニュー「実行数」で確認できる

## 制限の目安
- 1ファイル2GBまで（17〜23MBの動画は6回程度の送信で完了）
- Apps Scriptの無料枠：外部通信 20,000回／日（今回の用途では十分）
